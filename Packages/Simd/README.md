# Rux/Simd

Portable SIMD (Single Instruction, Multiple Data) operations and vectorized vector types for Rux.

## Features

- **Vector Types**: `Float32x4`, `Float64x2`, `Int32x4`, `Uint32x4`.
- **Parallel Arithmetic**: `Add`, `Sub`, `Mul`, `Div`, `Dot`, `Sum`, `Min`, `Max`.
- **Hardware Acceleration**: Automatic SSE/AVX and NEON vector acceleration.
