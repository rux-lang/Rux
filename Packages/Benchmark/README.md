# Rux/Benchmark

Standard micro-benchmarking, statistical timing, throughput analysis, and anti-optimization barriers for Rux.

## Features

- **Anti-Optimization**: `BlackBox` prevents compiler dead-code elimination.
- **Statistical Timing**: Iteration sampling, warm-up runs, mean elapsed calculation.
- **Throughput Measurement**: Bytes/second computation for data pipelines and cryptographic hashing.
