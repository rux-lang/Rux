# Json

JSON parsing and serialization.

> **Not implemented yet.** The package is published so its name and identity are reserved and its place in the standard set is fixed. `Src/Json.rux` is a placeholder that declares nothing, so importing from this package is an error rather than a silent no-op.

## Installation

```sh
rux add Rux/Json
```

## Planned surface

A document model, a parser that reports the position of a syntax error, and serialization through the `Stringable` protocol in [`Rux/Format`](../Format).
